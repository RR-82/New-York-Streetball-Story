# New York: Streetball Story

Нуарный уличный баскетбол в браузере: карьера по восьми районам Нью-Йорка, боссы со своими приёмами, 3D-карта города, турнир, быстрые матчи 1×1 / 2×2 / 3×3, газета после матча, раздевалка.

Игра — это статический сайт: один файл `index.html` и несколько вспомогательных. **Сервер, база данных и сборка (React, npm) не нужны.**

## Как опубликовать на GitHub Pages

1. Загрузите все файлы из этого архива в корень репозитория (кнопка **Add file → Upload files** на GitHub, перетащите содержимое папки целиком, включая `.nojekyll`).
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main**, папку **/ (root)**, нажмите **Save**.
4. Через 1–2 минуты игра откроется по адресу
   `https://rr-82.github.io/New-York-Streetball-Story/`

Обновление игры: замените `index.html` в репозитории — Pages перевыложит сайт сам.

## Что в архиве

| Файл | Зачем |
|---|---|
| `index.html` | Вся игра: разметка, стили, код |
| `config.js` | Настройки без правки кода: реклама на площадке |
| `manifest.webmanifest`, `icons/` | Значок и название при «Добавить на экран Домой», основа для сторов |
| `vendor/` | Место для локальной копии 3D-движка (см. ниже) |
| `.nojekyll` | Говорит GitHub Pages отдавать файлы как есть |
| `docs/PLATFORMS.md` | Как дальше идти в App Store, Google Play и Telegram |

## Что работает без Claude

Всё, кроме онлайна:

- карьера, карта, боссы, уровни, навыки, звёзды, турнир, быстрые матчи, обучение, заставка, газета, раздевалка, музыка, стили — без изменений;
- прогресс хранится на устройстве игрока (localStorage браузера). На другом устройстве или после очистки данных сайта прогресс начнётся заново;
- реклама MYBE в центре площадки берётся из `config.js`.

## Что требует сервера

**Онлайн 1 на 1.** В версии внутри Claude связь между игроками давала платформа Claude. На обычном сайте её нет, поэтому кнопка «Онлайн» остаётся в меню, но сообщает, что связь не подключена. Код онлайна из игры не удалён. Чтобы онлайн заработал на сайте, нужен сервис связи: либо свой небольшой сервер (WebSocket), либо готовый сервис реального времени (Firebase, Supabase, Ably и подобные). Это отдельная работа.

**Общий прогресс между устройствами и редактор рекламы в игре** тоже работали через базу Claude. На сайте прогресс локальный, а реклама правится в `config.js`.

## Внешние зависимости

Игра загружает из интернета две вещи:

- 3D-движок three.js r128 с `cdnjs.cloudflare.com`;
- шрифты Rubik с Google Fonts (без них игра работает на системном шрифте).

Для полностью автономной сборки (обязательно для App Store и Google Play) положите файл three.js r128 в `vendor/three.min.js` — игра подхватит его сама, если сеть недоступна:

```
curl -L -o vendor/three.min.js https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
```

## Проверка после публикации

- Компьютер: Chrome, Safari, Firefox, Edge — заставка, меню, матч, карта карьеры.
- iPhone и Android: вертикально и горизонтально, касания, звук после первого нажатия.
- «Поделиться → На экран Домой» — игра открывается на весь экран со своим значком.

## Права

Музыка в игре сгенерирована кодом игры. Названия клубов и брендов не используются. Логотип MYBE принадлежит владельцам игры.
